# 官方 POS 窗口识别

官方 POS 的“运行中”判断、自动切回官方窗口和老板键避险现在使用同一套配置：

- 识别对象是 Windows 可见的顶层窗口标题；
- 窗口标题关键词是必填项，辅助进程名由窗口选择自动记录；
- 不再用固定进程名或串口日志文件单独猜测官方 POS；
- 串口日志仍只负责读取官方 POS 产生的称重数据。

## 第一次启动

1. 先启动官方 POS。
2. 启动本 POS，输入登录密码。
3. 在“选择官方 POS 窗口”列表中点选官方收银主窗口，点击“确认此窗口”。
4. 系统保存窗口标题识别词和辅助进程名，然后继续检测。

如果列表为空，先启动官方 POS，再点击“刷新窗口”。未完成选择时不能通过官方 POS 生产检测。

## 修改识别窗口

进入“系统设置 → 系统运行与触屏悬浮球 → 官方 POS 窗口识别”，点击“检测并选择窗口”即可更换。窗口标题发生升级变化时，也可以在同一页修改识别词后点击“保存系统设置”，再用“按当前配置检测”验证。

每次启动都按已保存的窗口识别词检测；如果官方 POS 没有运行，检测页会显示“未找到官方 POS 窗口”。
