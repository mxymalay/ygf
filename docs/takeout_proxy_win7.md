# 外卖 RAW 打印中继（Windows 7）

这个功能拦截的是官方 POS 发送到一个专用“中继打印队列”的外卖 RAW/ESC-POS 数据，再由本 POS 重排并发送到真实热敏打印机。它不会、也不能拦截已经直接发到物理打印机的打印任务。

## 首次配置

1. 在本 POS 的“系统设置 → 打印机设置”选择真实物理热敏打印机；不要选择下面要新建的中继队列。
2. 进入“外卖打印中继与排序”，填写一个未使用的队列名，例如 `YGF 外卖中继`，端口保持 `9101`，先点击“启动中继”和“测试中继识别”。
3. 打开 Windows 7 的“设备和打印机”，添加本地打印机，选择“创建新端口 → Standard TCP/IP Port”。主机名填写 `127.0.0.1`；端口号填写 `9101`；协议选择 `RAW`。
4. 给这个新队列安装可原样输出 ESC/POS 的热敏打印驱动。一般可使用真实热敏打印机已安装的同款驱动，但这个队列的名称必须与物理打印机不同。
5. 在官方 POS 中，仅把“外卖订单/制作单”的打印机改为 `YGF 外卖中继`。堂食、收款等其它打印仍按门店原设置。
6. 回到本 POS 点击“检查 Windows 队列”。通过后，在官方 POS 打一张测试外卖单。页面的“最近任务”应出现订单，物理机只会收到重排后的制作联和存根联。

## 日常使用

- 中继启动后，只接受本机 `127.0.0.1` 的连接；不会开放给局域网。
- 收到非外卖内容或无法识别菜品的任务时，系统不会自动打印，避免错单。
- 同一平台订单号只会自动打印一次。需要补打时，使用“重打最近外卖单”；该操作会明确记为重打并累计联数。
- “制作联份数”和“存根联份数”至少保留一联；两者为 0 时系统会拒绝打印。

## 停用 / 删除

1. 先在官方 POS 将外卖打印机改回原物理打印机或其它合法队列。
2. 在本 POS 点击“停止中继”，再点击“清除本页中继配置”。这一步不会删除 Windows 打印机，避免误删真实设备。
3. 确认官方 POS 已不再使用该队列后，才在“设备和打印机”中手工删除 `YGF 外卖中继` 队列和其 TCP/IP 端口。

## 排查

- “端口被占用”：换一个未占用端口，例如 `9102`，同时修改 Windows 队列端口。
- “收到任务但没有菜品”：中继队列的驱动没有输出 RAW 文本；换用支持 ESC/POS RAW 的热敏驱动。
- “打印回环”：本 POS 的真实打印机误选成了中继队列。系统会阻止已填写队列名的同名输出；改回物理热敏打印机。
